橫向全螢幕才能遊玩
載入中 0%
開始後會自動切換成橫向全螢幕
目前在 LINE 等內建瀏覽器：無法全螢幕與安裝。請點右上角「⋯」→「用預設瀏覽器開啟」。

Android（Chrome）

  1. 用 Chrome 開啟遊戲網址。
  2. 點右上角「⋮」選單。
  3. 選「安裝應用程式」（舊版叫「加到主畫面」）。
  4. 確認後桌面會出現遊戲圖示，點它就能全螢幕玩。

iPhone / iPad（Safari）

  1. 一定要用 Safari 開啟遊戲網址（其他瀏覽器沒有這個選項）。
  2. 點網址列旁或下方的「分享」鈕（方框加向上箭頭）。
  3. 往下滑，選「加入主畫面」。
  4. 點右上角「新增」，桌面就會出現遊戲圖示。
